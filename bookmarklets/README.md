# 🔖 북마클릿(Bookmarklet) 초보자 가이드

북마클릿은 별도의 프로그램을 설치하지 않고도, 브라우저의 **즐겨찾기(북마크)** 버튼을 한 번 클릭해 웹페이지에서 특정 기능(세미나 일괄 신청, 복사 제한 해제 등)을 바로 실행하는 기능입니다.

---

## 📌 1분 요약: 북마클릿 등록 3단계

1. 브라우저에서 북마크바를 켭니다 (`Ctrl + Shift + B`).
2. 북마크바의 빈 곳을 마우스 우클릭하고 **[페이지 추가]**를 클릭합니다.
3. **이름**을 적고, **URL**에 `javascript:...` 코드를 붙여넣은 뒤 **[저장]**을 누릅니다.

---

## 🚀 PC 브라우저 등록 가이드 (Chrome, Edge, Whale 공통)

### 1단계: 북마크바 띄우기
* **단축키**: `Ctrl + Shift + B` (Mac: `Cmd + Shift + B`)
* 주소창 바로 아래에 즐겨찾기 목록(북마크바)이 나타납니다.

### 2단계: 북마클릿 추가하기
1. 북마크바의 빈 공간에 **마우스 오른쪽 버튼을 클릭**합니다.
2. 메뉴에서 **[페이지 추가...]** (또는 [즐겨찾기 추가])를 클릭합니다.
3. 새 창이 뜨면 아래와 같이 입력합니다:
   * **이름**: 기억하기 쉬운 이름 입력  
     *(예: `🎯 닥터빌 세미나 일괄신청` 또는 `🔓 복사제한 해제`)*
   * **URL**: 등록할 `.txt` 파일 안의 **`javascript:...` 전체 내용**을 복사해서 그대로 붙여넣기
4. **[저장]** 버튼을 누르면 북마크바에 버튼이 생성됩니다.

> 💡 **Tip: [페이지 추가] 메뉴를 찾기 어려운 경우**  
> 현재 열려 있는 아무 웹사이트나 별표(⭐)를 눌러 북마크에 추가한 후,  
> 북마크바의 해당 버튼을 마우스 우클릭 -> **[수정]**을 눌러 URL 내용을 북마클릿 코드로 교체하셔도 됩니다.

---

## 🎮 북마클릿 실행 방법

1. **대상 웹사이트로 이동 및 로그인**  
   * 세미나 신청 북마클릿의 경우, [닥터빌](https://www.doctorville.co.kr)에 먼저 로그인합니다.
2. 브라우저 상단 북마크바에서 등록해 둔 **북마클릿 버튼을 클릭**합니다.
3. 화면에 안내 UI나 알림창이 뜨면서 자동으로 작업이 실행됩니다.

## 📱 스마트폰(모바일) 브라우저 사용법

> ⚠️ **주의: 풀버전([`auto_apply_full.txt`](https://raw.githubusercontent.com/wooooooooooook/DV-auto/main/bookmarklets/auto_apply_full.txt))의 모바일 등록 제한**  
> * **풀버전**은 UI와 대시보드 코드가 포함되어 있어(약 8.6KB) **모바일 브라우저의 URL 글자 수 제한으로 인해 모바일 기기에서 직접 붙여넣어 등록할 수 없습니다.**
> * **해결 방법 1 (추천)**: **PC 브라우저(Chrome/Edge 등)에서 먼저 북마클릿을 등록**해 두면, 같은 계정으로 **연동(동기화)된 스마트폰 브라우저에서도 그대로 불러와 사용**할 수 있습니다.
> * **해결 방법 2**: PC 없이 모바일에서 바로 등록하고 싶다면 길이가 짧은 **심플 버전([`auto_apply_simple.txt`](https://raw.githubusercontent.com/wooooooooooook/DV-auto/main/bookmarklets/auto_apply_simple.txt))**을 사용해 주세요.

### 모바일에서 실행하는 순서 (Chrome / Safari 공통)

1. **북마크 준비**:
   * **PC 연동 사용 시**: PC에서 풀버전 북마클릿을 등록해 두면 스마트폰에도 자동 동기화됩니다.
   * **모바일 직접 등록 시**: 아무 페이지나 북마크한 뒤 편집에서 [`auto_apply_simple.txt`](https://raw.githubusercontent.com/wooooooooooook/DV-auto/main/bookmarklets/auto_apply_simple.txt) 코드를 붙여넣습니다. (이름: `닥터빌신청` 등)
2. 스마트폰 브라우저로 [닥터빌](https://www.doctorville.co.kr)에 접속 후 **로그인**합니다.
3. 브라우저 **주소창**을 터치하고, 저장해 둔 북마클릿 이름(`닥터빌신청`)을 검색합니다.
4. 검색 결과 목록에 나타나는 **북마크 아이콘(⭐ 또는 🔖)**을 터치하면 즉시 실행됩니다!

## ⚠️ 초보자가 자주 겪는 문제 & 주의사항 (FAQ)

* **Q. 모바일 브라우저 북마크에 풀버전 코드를 붙여넣었는데 저장이 안 되거나 잘려요.**  
  * 풀버전 코드는 약 8.6KB로 모바일 브라우저 북마크 입력창의 최대 허용 글자 수를 초과하기 때문입니다. **PC 브라우저에서 먼저 등록한 뒤 모바일과 연동(동기화)**해서 사용하시거나, 모바일에서는 **심플 버전([`auto_apply_simple.txt`](https://raw.githubusercontent.com/wooooooooooook/DV-auto/main/bookmarklets/auto_apply_simple.txt))**을 등록해 주세요.
* **Q. 주소창에 직접 복사해서 엔터를 쳤는데 아무 일도 안 일어나요.**  
  * 크롬/엣지 브라우저는 보안을 위해 주소창에 코드를 붙여넣을 때 맨 앞의 `javascript:` 접두사를 자동으로 지워버립니다. 주소창에 직접 붙여넣지 마시고 **반드시 북마크의 URL 칸에 등록**하여 클릭하세요.
* **Q. 버튼을 눌렀는데 세션 만료 또는 로그인이 필요하다고 나와요.**  
  * 북마클릿은 현재 브라우저의 로그인 상태를 이용해 API를 호출합니다. 반드시 사이트에 **로그인을 먼저 완료**한 상태에서 실행해 주세요.
* **Q. 다른 사이트에서 누르면 어떻게 되나요?**  
  * 닥터빌 북마클릿은 다른 웹사이트에서의 오작동을 막기 위해 닥터빌 사이트가 아닐 경우 경고창을 띄우고 동작하지 않도록 안전하게 보호되어 있습니다.
