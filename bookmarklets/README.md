# 🔖 북마클릿(Bookmarklet) 초보자 가이드

**즐겨찾기 버튼 하나로 세미나를 한꺼번에 신청**할 수 있는 기능입니다.
프로그램 설치도, 앱 설치도 필요 없습니다. 아래 순서대로 **한 번만 등록**해 두면 계속 쓸 수 있습니다.

---

## ⏱️ 30초 요약

| 내 환경 | 이렇게 하세요 |
| :--- | :--- |
| **PC(데스크톱)** | 풀버전 코드를 즐겨찾기에 등록 → 즐겨찾기 바의 버튼 클릭 |
| **스마트폰만 있음** | 심플 버전 코드를 폰 즐겨찾기에 직접 등록 → 주소창에서 이름 검색해 실행 |
| **PC와 폰 둘 다** | PC에서 풀버전을 등록하면 폰으로 **자동 동기화**됩니다 (가장 쉬움) |

> 처음이라면 아래 **3번(데스크톱 등록하기)** 부터 그대로 따라 하세요.

---

## 1. 북마클릿이 뭐예요?

- 즐겨찾기(북마크)에 **짧은 코드를 저장**해 두는 것입니다.
- 그 즐겨찾기를 클릭하면, 지금 열려 있는 닥터빌 페이지에서 **세미나 일괄 신청** 같은 작업이 자동으로 실행됩니다.
- 주소창에 코드를 직접 붙여넣는 방식이 아니라, **즐겨찾기 URL 칸에 저장해서 클릭하는 방식**이라는 점만 기억하면 됩니다.

---

## 2. 시작 전 준비 (공통)

1. 크롬, 엣지, 웨일, 사파리 중 **평소 쓰는 브라우저**를 엽니다.
2. [닥터빌](https://www.doctorville.co.kr)에 접속해 **로그인**합니다.
   * 북마클릿은 현재 브라우저의 로그인 상태로 동작하므로 로그인이 꼭 필요합니다.
3. 아래 **파일 목록**에서 **등록할 파일을 먼저 정합니다.**
   * PC라면 → `auto_apply_full.txt` (풀버전, 추천)
   * 스마트폰에서 직접 등록한다면 → `auto_apply_simple.txt` (심플 버전)

---

## 3. 🖥️ 데스크톱(PC)에서 등록하기

> 크롬 / 엣지 / 웨일 모두 거의 같습니다. (맥은 `Ctrl` 대신 `Cmd`)

### 1단계 — 즐겨찾기 바 보이게 하기
* 키보드에서 **`Ctrl + Shift + B`** 를 누릅니다.
* 주소창 바로 아래에 즐겨찾기 목록 줄(즐겨찾기 바)이 생깁니다.

### 2단계 — 코드 복사하기
* 아래 **파일 목록**에서 원하는 파일을 클릭합니다.
* 화면에 코드가 보이면 **전체 선택(`Ctrl + A`) → 복사(`Ctrl + C`)** 합니다.
* `javascript:` 로 시작하는 **맨 앞 글자부터 끝까지 전부** 복사해야 합니다.

### 3단계 — 즐겨찾기 추가하기
* 즐겨찾기 바의 **빈 곳**에 마우스 오른쪽 버튼을 클릭합니다.
* 메뉴에서 **[페이지 추가...]** (엣지는 **[즐겨찾기 추가]**)를 클릭합니다.

### 4단계 — 이름과 주소 입력하기
* **이름**: 알아보기 쉬운 이름을 적습니다. (예: `일괄등록 북마클릿`)
* **URL**: 2단계에서 복사한 코드를 붙여넣습니다. (`Ctrl + V`)
* **[저장]** 을 누릅니다.

### 5단계 — 확인
* 즐겨찾기 바에 방금 만든 버튼이 생겼으면 끝입니다.
* 이제 닥터빌 페이지에서 그 버튼을 클릭하면 실행됩니다.

> 💡 **[페이지 추가] 메뉴가 안 보인다면**
> 아무 웹사이트에서 별표(⭐)를 눌러 즐겨찾기를 하나 만든 뒤, 즐겨찾기 바에서 그 항목을 **오른쪽 클릭 → [수정]** 하여 주소를 코드로 바꿔도 됩니다.

---

## 4. 📱 스마트폰에서 사용하기

스마트폰은 **방법 A(추천)** 와 **방법 B** 중 하나를 고르면 됩니다.

### 방법 A (추천) — PC에서 등록하고 폰으로 자동 동기화

1. 위 **3번 데스크톱 등록하기**를 PC에서 그대로 진행합니다. (풀버전 사용)
2. 스마트폰 브라우저에서 **PC와 같은 계정으로 로그인**되어 있는지 확인합니다.
   * 크롬(안드로이드): 구글 계정 로그인 → 즐겨찾기 자동 동기화
   * 사파리(아이폰): iCloud 사파리 동기화 켜기
3. 잠시 기다리면 폰 즐겨찾기에도 같은 버튼이 생깁니다.
4. 폰에서 실행하는 방법은 아래 **5번**을 참고하세요.

### 방법 B — 스마트폰에서 직접 등록하기 (심플 버전)

> ⚠️ **풀버전은 폰에서 직접 등록할 수 없습니다.** 코드가 약 8.6KB로 길어 스마트폰 브라우저의 주소 입력창 글자 수 제한을 넘기 때문입니다. 폰에서 직접 등록할 때는 **반드시 심플 버전**을 사용하세요.

1. `auto_apply_simple.txt` 파일을 열어 코드를 **전체 복사**합니다.
   * 폰에서 파일 열기가 어려우면, PC에서 복사해 **메모나 메일로 폰에 보내** 두고 복사해도 됩니다.
2. 아무 웹페이지나 즐겨찾기에 추가합니다. (북마크/즐겨찾기 추가)
3. 방금 만든 즐겨찾기를 **편집**합니다.
4. **이름**을 `닥터빌신청` 처럼 알아보기 쉽게 적고, **주소(URL)** 칸에 복사한 코드를 붙여넣습니다.
5. 저장합니다. (코드가 잘리지 않았는지 저장 후 한 번 더 확인하세요)

---

## 5. ▶️ 실행하기 (PC·스마트폰 공통)

1. [닥터빌](https://www.doctorville.co.kr)에 **로그인**합니다.
2. 북마클릿을 실행합니다.
   * **PC**: 즐겨찾기 바의 버튼을 클릭
   * **스마트폰**: 주소창을 터치하고 저장한 이름(예: `닥터빌신청`)을 검색한 뒤, 검색 결과의 **북마크 항목을 터치**
3. 화면에 뜨는 안내를 따라 진행합니다.
   * 풀버전: 오른쪽 위 대시보드에서 진행률과 성공/실패 결과를 보여줍니다.
   * 심플 버전: 확인창(예/아니오)으로 진행합니다.

## ⚠️ 자주 막히는 곳

* **주소창에 코드를 붙여넣었는데 아무 일도 안 일어나요.**
  * 크롬·엣지는 보안 때문에 주소창에 붙여넣은 `javascript:` 를 자동으로 지웁니다. 주소창에 직접 붙여넣지 말고, **즐겨찾기의 URL 칸에 저장한 뒤 그 즐겨찾기를 클릭**하세요.
* **스마트폰에서 풀버전 코드가 저장되지 않거나 잘려요.**
  * 위에서 설명한 글자 수 제한 때문입니다. **심플 버전**을 쓰거나, **PC에서 등록한 뒤 동기화**하세요.
* **"로그인이 필요합니다" 또는 "세션이 만료되었습니다"가 떠요.**
  * 닥터빌에 로그인한 뒤 다시 실행하세요.
* **다른 사이트에서 눌렀더니 경고만 뜨고 동작하지 않아요.**
  * 정상입니다. 닥터빌 사이트가 아닐 때 오작동을 막는 안전장치입니다.
* **버튼을 눌러도 반응이 없어요.**
  * 페이지를 새로고침한 뒤 다시 눌러보고, 그래도 안 되면 로그인 상태를 확인하세요.
